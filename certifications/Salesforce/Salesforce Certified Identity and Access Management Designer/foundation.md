### **Identity Governance**

### 1. Which combination represents true multi-factor authentication (MFA)?

- [ ] **A)** Password and security question
- [ ] **B)** Two different passwords
- [ ] **C)** Password and TOTP from Salesforce Authenticator
- [ ] **D)** Username and password

<details>
<summary> 🔍 Reveal Answer</summary>
   
#### **✅ Correct Answer: C**
 
> 💡  **Explanation** 
> 
> True MFA requires unique factor categories. A password is knowledge; TOTP is possession; using both satisfies MFA.
 
 
</details>

### 2. Which of the following are authentication factor categories used in MFA? Select all that apply.

- [ ] **A)** Knowledge

### 7. In a multi-factor authentication design, which category does a TOTP code generated by the Salesforce Authenticator app belong to?

</details>
