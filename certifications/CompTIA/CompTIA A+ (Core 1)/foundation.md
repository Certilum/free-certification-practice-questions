### **Hardware**

### 1. Which cable type uses an RJ45 connector and twisted-pair copper wiring?

- [ ] **A)** VGA
- [ ] **B)** Cat 6a
- [ ] **C)** HDMI
- [ ] **D)** RG-6

<details>
<summary> 🔍 Reveal Answer</summary>
   
#### **✅ Correct Answer: B**
 
> 💡  **Explanation** 
> 
> Ethernet copper cables such as Cat 6a use RJ45 connectors and twisted-pair wiring. VGA, HDMI, and RG-6 use different connector types and signaling.
 
 
</details>

### 2. Which two characteristics apply to USB-C?

- [ ] **A)** It is reversible.
- [ ] **B)** It supports Power Delivery up to 100 W.
- [ ] **C)** It only carries USB 2.0 signals.
- [ ] **D)** It uses a blue insert to indicate speed.

<details>
<summary> 🔍 Reveal Answer</summary>
   
#### **✅ Correct Answer: A, B**
 
> 💡  **Explanation** 
> 
> USB-C is reversible and can deliver up to 100 W. Blue inserts identify older USB 3.x Type-A ports, not USB-C.
 
 
</details>

### 4. Which video connector carries only an analog signal?

- [ ] **A)** VGA
- [ ] **B)** DVI-D
- [ ] **C)** HDMI
- [ ] **D)** DisplayPort

<details>
<summary> 🔍 Reveal Answer</summary>

</details>

### 5. Which two statements about DVI-to-VGA adapters are correct?

- [ ] **D)** HDMI can be converted to VGA with a passive adapter.

<summary> 🔍 Reveal Answer</summary>
   
#### **✅ Correct Answer: A, B**
 
> 💡  **Explanation** 
> 
> DVI-I and DVI-A include analog pins, so a passive adapter works. DVI-D is digital-only and needs an active converter.
 
 
</details>

- [ ] **A)** 443
- [ ] **B)** 80

- [ ] **D)** 143

<details>
<summary> 🔍 Reveal Answer</summary>

<summary> 🔍 Reveal Answer</summary>
   
#### **✅ Correct Answer: A, B**
 
> 💡  **Explanation** 
> 
> POP3 downloads messages and IMAP synchronizes them; SMTP sends and relays email, while SNMP monitors network devices.

<details>
<summary> 🔍 Reveal Answer</summary>
   
#### **✅ Correct Answer: A**

<summary> 🔍 Reveal Answer</summary>
