### **Software Troubleshooting**

### 24. According to the CompTIA A+ troubleshooting methodology, what is the first step when a user reports an application crash?

- [ ] **A)** Reinstall the application immediately
- [ ] **B)** Identify the problem by gathering information from the user
- [ ] **C)** Establish a theory of probable cause
- [ ] **D)** Implement the solution without further analysis

<details>
<summary> 🔍 Reveal Answer</summary>
   
#### **✅ Correct Answer: B**
 
> 💡  **Explanation** 
> 
> The CompTIA A+ troubleshooting methodology begins with identifying the problem. The technician must gather information from the user through open-ended and closed-ended questions to understand when the error started, what actions precede it, and whether it affects other applications. This step must be completed before forming theories or applying fixes.
 
 
</details>

### 25. Which two activities belong to the 'identify the problem' phase of the CompTIA A+ troubleshooting methodology? (Select TWO)

- [ ] **A)** Ask the user when the problem started
- [ ] **B)** Duplicate the problem in a controlled manner
- [ ] **C)** Implement a fix immediately
- [ ] **D)** Reinstall the operating system

<details>
<summary> 🔍 Reveal Answer</summary>
   
#### **✅ Correct Answer: A, B**
 
> 💡  **Explanation** 
> 
> The identify the problem phase requires gathering information from the user, asking about recent changes, and duplicating the issue in a controlled way. Implementing fixes or reinstalling the OS occurs later in the methodology. Documentation is the final step, not part of initial identification.
 
 
</details>

### 29. A Windows computer displays 'BOOTMGR is missing' during startup. What is the best next step?

```text
BOOTMGR is missing. Press Ctrl+Alt+Del to restart.
```

- [ ] **A)** Reinstall Windows from scratch
- [ ] **B)** Run Startup Repair from the Windows Recovery Environment
- [ ] **C)** Replace the hard drive
- [ ] **D)** Reset this PC with Remove everything

<details>
<summary> 🔍 Reveal Answer</summary>
   
#### **✅ Correct Answer: B**
 
> 💡  **Explanation** 
> 
> A 'BOOTMGR is missing' error indicates boot configuration data corruption. Startup Repair from WinRE is designed to fix boot records, rebuild the BCD, and repair the MBR without affecting user data. Reinstalling Windows or resetting the PC is too destructive at this stage and violates the least-intrusive-first principle.
 
 
</details>

### 30. What is the primary purpose of booting Windows into Safe Mode during troubleshooting?

- [ ] **A)** To run a full antivirus scan
- [ ] **B)** To load a minimal set of drivers and services for diagnosis
- [ ] **C)** To reinstall Windows drivers automatically
- [ ] **D)** To access the Command Prompt directly

<details>
<summary> 🔍 Reveal Answer</summary>
   
#### **✅ Correct Answer: B**
 
> 💡  **Explanation** 
> 
> Safe Mode loads only essential drivers and services, allowing the technician to determine whether a problem is caused by third-party software, drivers, or startup programs. If the issue disappears in Safe Mode, the cause is likely a non-Microsoft driver or application. This is a foundational diagnostic technique in the CompTIA methodology.
 
 
</details>
