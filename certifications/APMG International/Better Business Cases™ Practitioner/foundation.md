### 6. Using the code snippet, which metric indicates a project adds value after discounting?

```python
def compute_npv(cashflows, discount_rate):
    npv = -cashflows[0]
    for t in range(1, len(cashflows)):
        npv += cashflows[t] / (1 + discount_rate)**t
    return npv

# Example: initial outlay 100, returns 50, 60, 70 at 10%
print(compute_npv([100,50,60,70], 0.10))  # Output: 47.6
```

- [ ] **A)** Net Present Value (NPV)
- [ ] **B)** Internal Rate of Return (IRR)

<details>
<summary> 🔍 Reveal Answer</summary>
   
#### **✅ Correct Answer: A**
 
> 💡  **Explanation** 
> 
> A positive NPV indicates the project generates more value than its cost after discounting future cash flows.
 
 
</details>
