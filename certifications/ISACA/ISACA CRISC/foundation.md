### 9. In the CRISC framework, which statement best defines a risk event?

- [ ] **A)** A distinct occurrence that may affect objectives
- [ ] **B)** A weakness in an asset
- [ ] **C)** A potential cause of harm
- [ ] **D)** A control designed to reduce impact

<details>
<summary> 🔍 Reveal Answer</summary>
   
#### **✅ Correct Answer: A**
 
> 💡  **Explanation** 
> 
> A risk event is a distinct occurrence or change of circumstances that could affect objectives. A weakness is a vulnerability, and a potential cause is a threat.
 
 
</details>

### 25. Which principle requires multiple layers of security control across network, host, application, data, and administrative domains?

- [ ] **A)** Least Privilege
- [ ] **B)** Defense in Depth
- [ ] **C)** Separation of Duties
- [ ] **D)** Deny-by-Default

<details>
<summary> 🔍 Reveal Answer</summary>
   
#### **✅ Correct Answer: B**
 
> 💡  **Explanation** 
>

</details>

- [ ] **C)** Availability
- [ ] **D)** Anonymity

<details>
<summary> 🔍 Reveal Answer</summary>
   
#### **✅ Correct Answer: A, B, C**
 
> 💡  **Explanation** 
>

</details>

### 30. Given the following configuration, which security architecture principle is being ignored?

```yaml
# Example server configuration
server:
  default_ports:
    - "22"
    - "80"
    - "443"
    - "3306"  # Unnecessary database port exposed
  fail_mode: "open"  # Should be 'closed' to deny access on failure
```

- [ ] **A)** Secure by Default and Fail Secure
- [ ] **B)** Defense in Depth
- [ ] **C)** Separation of Duties
- [ ] **D)** Architecture Alignment with Enterprise Objectives

<details>
<summary> 🔍 Reveal Answer</summary>
   
#### **✅ Correct Answer: A**
 
> 💡  **Explanation** 
> 
> Systems should start from a secure configuration with unnecessary services and ports disabled, and should fail into a safe state that denies access. The configuration violates secure-by-default and fail-secure principles.
 
 
</details>
